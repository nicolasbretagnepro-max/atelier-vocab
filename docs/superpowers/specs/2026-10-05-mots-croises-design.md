# Mots croisés mobiles

Demande : nouvelle brique accessible depuis l'accueil, développée par lots dans le dépôt existant. La proposition de sept mots (cinq dus, deux maîtrisés), validation mot par mot et écran dédié a été présentée ; l'utilisateur demande explicitement de préparer les lots et de développer.

Le jeu utilise uniquement le vocabulaire général. Sept mots visés, repli à six puis cinq ; aucun résultat avec moins de cinq mots. Quota arrondi 70/30, candidats dus triés par fragilité et taux de réussite historique, appuis issus du statut Maîtrisé existant. Aucun nouveau mot ni mot futur fragile pour compléter le quota. Lettres françaises normalisées (accents, œ), identifiants du profil conservés, définitions dévoilant le mot et réponses de plus de onze lettres exclues. Grille connexe de onze lignes et colonnes maximum, sans collision ni voisinage parasite. Les alternatives restent dans les deux catégories pédagogiques.

Un moteur indépendant et un Worker produisent la grille avec une recherche bornée. L'écran de génération affiche un état d'attente et un message utile si les pools ou les intersections sont insuffisants. Le Worker est annulé à la fermeture. Pas de bibliothèque ni service externe, pas de backend.

Écran mobile : cases sélectionnables, surbrillance du mot, numérotation et orientation, carte de définition 18 px sous la grille, inputs 20 px, déplacement automatique, retour arrière, collage, changement d'orientation aux intersections. Le viewport visuel suit le clavier ; carte et boutons restent accessibles. La grille peut défiler uniquement verticalement lorsque le clavier réduit fortement l'espace. Cases minimum 28 px sur iPhone ; boutons 44 px. Pas de blocage du zoom utilisateur. Navigation clavier et réduction des animations.

La première vérification complète donne une seule évaluation par mot et par grille. Incomplet : aucune note. Premier échec ou révélation : again ; correction ultérieure sans nouvelle note. Première réussite autonome : good en mode context, car les croisements apportent une aide. Si toutes les lettres viennent déjà d'intersections validées, aucune note SRS n'est accordée, même en utilisant Révéler. Les appuis maîtrisés ne modifient ni le SRS ni les XP. Le jeu conserve son état lorsqu'il est fermé puis rouvert dans le même écran ; la création explicite d'une nouvelle grille recommence la sélection. Les progrès pédagogiques enregistrés restent persistants. Aucun bonus de fin.

Le mode est accessible séparément sur l'accueil ; pas de proposition automatique après une révision dans cette version, afin de ne pas réévaluer immédiatement les mêmes mots. La carte indique le mélange réellement placé. PWA : mettre en cache moteur, Worker, CSS et JSX, renouveler la version. Publication non incluse.

Vérification : normalisation, quotas, profils insuffisants, bornes de calcul, collisions, connexité, lettres communes, absence de mot divulgué, validation unique, reprise, indices fournis, effet sur calendrier et anciens profils. Navigateur : accueil, petit profil sans grille, jeu avec grille, erreur, correction, clavier, fermeture/reprise, tailles 393×852 et clavier simulé. Safari iPhone physique reste à vérifier sur l'appareil réel.
